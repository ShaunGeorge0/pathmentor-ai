ROLE: Machine Learning Engineer

OVERVIEW

Machine Learning Engineers design, build, train, deploy, and maintain machine learning systems in production environments. They bridge the gap between research and software engineering by transforming machine learning models into scalable applications that solve real-world business problems.

CORE RESPONSIBILITIES

* Develop machine learning models for production use.
* Build and maintain model training pipelines.
* Design evaluation and benchmarking workflows.
* Deploy machine learning systems to cloud environments.
* Monitor model performance and reliability.
* Create scalable inference services.
* Develop feature engineering and data processing pipelines.
* Collaborate with data scientists, software engineers, and product teams.
* Maintain production-grade codebases and infrastructure.
* Improve AI system performance, scalability, and reliability.
