# ROLE: Full Stack Developer

## OVERVIEW

Full Stack Developers design, develop, and maintain both frontend and backend components of web applications. They work across the entire software stack, including UI, APIs, databases, and deployment systems, ensuring applications are scalable, secure, and performant.

## CORE RESPONSIBILITIES

- Design, develop, and maintain full-stack web applications.
- Build and integrate RESTful APIs and third-party services.
- Develop responsive and interactive frontend interfaces.
- Implement backend services and business logic.
- Manage database design and data flow.
- Optimize applications for performance, scalability, and security.
- Collaborate with designers, backend developers, and product teams.
- Write clean, reusable, and maintainable code.
- Perform debugging, testing, and code reviews.
- Participate in system design and architecture discussions.
